# Playing Through Time

An interactive research website exploring the history of traditional Indian games and their connections to modern sports.

## Open the website on a Mac

1. On this repository page, select **Code → Download ZIP**.
2. Double-click the downloaded ZIP to extract it.
3. Open the extracted folder and double-click **index.html**. Choose Safari or Chrome if asked.

Keep **index.html**, **assets/**, and **sources/** together. The site needs no installation and works offline; internet is only needed for links to external source records.

## Publish or update the Netlify website

Upload the complete project folder to Netlify, with **index.html** at the folder root and the **assets/** and **sources/** folders alongside it. Do not upload only index.html.

## Project contents

- Research pages, historical image gallery, and interactive quizzes
- Local images in **assets/**
- Four original research reports in **sources/**
- Image attributions and source records in **CREDITS.md**
- The original research text, quiz questions, scoring, and navigation
