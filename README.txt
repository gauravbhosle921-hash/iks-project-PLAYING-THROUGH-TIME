PLAYING THROUGH TIME

Open the website on a Mac
1. Double-click the ZIP file to extract it.
2. Open the extracted Playing_Through_Time folder.
3. Double-click index.html. If macOS asks, choose Safari or Chrome.

The site needs no installation or server. Its images and research PDFs are included
in the folder and work offline. Internet access is needed only if you choose an
“Open source record” link in the visual archive.

The site includes 200 preserved quiz questions. The source bank contains 51
Chaturanga questions, 49 Pachisi questions, and 50 questions each for Gilli-Danda
and wrestling. Quiz progress and scoring use the actual number of questions for
each game, so every preserved question can be answered and scored correctly.

The four original research reports are in sources/.
Image attribution details and source records are in CREDITS.md.

The header has a “Wallpaper: On” control to pause or resume the moving background,
and a “Sound: On” control to mute or enable the short click chime.

The brand now has an animated chess-knight emblem. A pointed chess-knight cursor follows the pointer on mouse computers and replaces
the standard arrow, with a click flourish. It stays hidden on touchscreens; text
fields keep their normal text cursor. Drag-selected text appears black on antique gold.

Publish this site on Netlify
1. Extract the Netlify ZIP on your Mac.
2. Go to https://app.netlify.com/drop.
3. Drag the entire extracted folder into the drop zone. Do not upload only index.html.

The folder contains index.html at its root plus the assets/ and sources/ folders
that the web page loads.
